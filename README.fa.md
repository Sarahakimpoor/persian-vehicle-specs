# مشخصات خودرو به فارسی

کتابخانه‌ای مستقل برای نمایش مشخصات فنی خودرو با برچسب فارسی، اعداد و واحدهای
فارسی، ترجمهٔ امکانات و دسته‌بندی متناسب با نوع پیشرانه. این نسخه از بخش نمایش
یک سامانهٔ خودرویی استخراج شده و به پایگاه داده، React یا کلید API نیاز ندارد.

## اجرای سریع

Node.js نسخهٔ ۲۲٫۱۸ یا بالاتر لازم است؛ برای توسعه نسخهٔ ۲۴ پیشنهاد می‌شود.
نیازی به نصب بسته‌های دیگر نیست.

```sh
npm test
npm run example
```

این بسته هنوز در npm منتشر نشده است. برای استفاده در پروژهٔ دیگر، ابتدا
`npm run build` را اجرا کنید و سپس مسیر محلی بسته را با `npm install` نصب کنید.
JavaScript به صورت ES module و تعریف نوع برای TypeScript ارائه می‌شود.

```js
import { formatSpecValue } from '@sarahakimpoor/persian-vehicle-specs';
formatSpecValue(25.7, null, null, 'kwh'); // ۲۵٫۷ کیلووات‌ساعت
formatSpecValue(null, 'AWD', null, null); // چهار چرخ متحرک
```

مقدار صفر و مقدار بولی `false` حفظ می‌شوند. مقدار خالی، متن سفید و عدد نامتناهی
یا نامعتبر به `null` تبدیل می‌شوند. مقدار بولی اولویت دارد؛ با قالب `text`، متن
اولویت دارد؛ در حالت عادی عدد معتبر پیش از متن نمایش داده می‌شود. متن دارای
واحد بدون افزودن دوبارهٔ واحد نمایش داده می‌شود. این ابزار تبدیل واحد انجام نمی‌دهد.

## دسته‌بندی مشخصات

تابع `buildDisplaySections` آرایه‌های `sections` و `features` را در یک شیء
`VehicleTechnical` می‌گیرد و گروه‌های قابل‌نمایش را برمی‌گرداند. برای مشخصات
شناخته‌شده، برچسب و ترتیب داخلی استفاده می‌شود؛ مشخصات سفارشی برچسب و ترتیب
ورودی را حفظ می‌کنند. [نمونهٔ ساختگی](examples/fixture.mjs) شکل ورودی را نشان می‌دهد.

پیشرانه‌های پشتیبانی‌شده: `ICE`، `MHEV`، `HEV`، `PHEV` و `BEV`.
برای پیشرانهٔ نامشخص، مشخصات شناخته‌شدهٔ مختص یک پیشرانه حذف می‌شوند؛ مشخصات
عمومی و سفارشی باقی می‌مانند. ورودی تغییر نمی‌کند و فیلدهای اضافی به خروجی کپی نمی‌شوند.
متن خروجی را با `textContent` یا سازوکار امن نمایش متن در چارچوب خود نمایش دهید.

## نمونهٔ مرورگر

```sh
npm run build
python3 -m http.server 8000 --bind 127.0.0.1
```

نشانی `http://127.0.0.1:8000/examples/browser.html` را باز کنید و نوع پیشرانه را
تغییر دهید. تمام اعداد نمونه ساختگی‌اند و ادعایی دربارهٔ خودروی واقعی نیستند.

این بسته شامل اطلاعات مشتری، سفارش، قیمت، کلید دسترسی یا منطق مالی نیست.
پایگاه اطلاعات خودرو یا ابزار تأیید صحت مشخصات هم نیست. دسته‌بندی فعلی کامل نیست؛
برای `EREV` هنوز نگاشت اختصاصی وجود ندارد. سابقهٔ انتشار عمومی و استفادهٔ دیگران
برای نسخهٔ ۰٫۱٫۰ هنوز شکل نگرفته است.
