# Contributing

Use Node.js 24, run `npm test` and `npm run example`, and open a focused pull request.
No dependency installation is required. Include a regression test when changing
formatting, grouping or applicability. Keep `types/index.d.ts` aligned with exports.

For terminology changes, explain the wording and provide a reliable reference.
Do not add customer data, private URLs, credentials, production fixtures, or copied
manufacturer data without permission. Use synthetic examples. Discuss scope changes
in an issue before introducing service integrations or framework dependencies.
